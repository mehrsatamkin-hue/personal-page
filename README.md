# صفحهٔ شخصی مهرسا

سایت ایستا است: `index.html` و `styles.css`. مرحلهٔ build ندارد. فایل `index.html` را در مرورگر باز کنید، یا همین پوشه را بدون تنظیم اضافه به Vercel وصل کنید.

## عوض کردن متن

همهٔ نوشته‌ها در `index.html` است.

- نام، خط انگلیسی و معرفی یک‌خطی داخل `header` است.
- متن بخش درباره داخل `#about-heading` و پاراگراف زیر آن است.
- هر پروژه یک `<li>` در فهرست پروژه‌هاست. برای پروژهٔ تازه همان `<li>` را کپی کنید و نشانی، نام مخزن و توضیح را عوض کنید.
- پیوند گیت‌هاب در `footer` است.

## رنگ و حالت تیره

رنگ‌های حالت روشن در ابتدای `styles.css`، زیر `:root`، هستند. رنگ‌های حالت تیره داخل `prefers-color-scheme: dark` هستند و از تنظیم روشن یا تیرهٔ سیستم پیروی می‌کنند.

فونت وزیرمتن از گوگل‌فونت بارگذاری می‌شود. لینک فونت در `head` فایل `index.html` است.
